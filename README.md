## App Description

Social Sparks is a native Android application developed using Kotlin and Android Studio.

The purpose of the application is to help users maintain social connections during busy days. The user enters a time of day and the application provides a suitable social interaction suggestion.

## Features

- Text input for the time of day
- Social spark suggestions
- Reset button
- Input validation and error handling
- Logging using Android Log
- Simple and user-friendly interface

## Social Spark Suggestions

The application provides different suggestions depending on the time entered.

Examples include:

- **Morning:** Send a "Good morning" message to a family member.
- **Mid-morning:** Send a quick "Thank you" message to a colleague.
- **Afternoon:** Share a funny meme or interesting link with a friend.
- **Afternoon Snack Time:** Send a "thinking of you" message.
- **Dinner:** Call a friend or relative for a short catch-up.
- **After Dinner / Night:** Leave a thoughtful comment on a friend's post.
